# Fully Evolved Starter Roster Update

The starter roster now contains only the fully evolved starter Pokémon from Generations I–IX.
All first- and middle-stage starter species were removed from `data/species/` and the species manifest.

Koraidon, Miraidon, and Dragonite remain because they are not starter-stage roster entries.

All starter species use the game's 14-type system, have species data, abilities, learnsets, and four-move battle movesets.
